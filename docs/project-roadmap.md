# Дорожная карта проекта

Документ основан на текущем состоянии игры и требованиях из 'docs/game-improvements-s7.md'.

## Принципы roadmap
- Приоритет у изменений, влияющих на core-геймплей и удержание.
- Каждая крупная задача должна иметь измеримый критерий приемки.
- Все изменения геймплея синхронизируются с редактором уровней и HUD.

## Этап 1. Core-геймплей (высокий приоритет)
- [x] Переключить основной режим с таймера на **игру по ходам**.
- [x] Считать ход только при успешном действии игрока.
- [x] Убрать визуальную стрелку swap, оставить drag/click с единой анимацией.
- [x] Запускать активную фазу уровня с первого результативного действия.
- [x] Стабилизировать генерацию/рестарт (seed не ломает блокеры).

**Критерий готовности:** полный цикл партии по ходам работает без регрессий в каскадах, HUD и экране результата.

## Этап 2. Цели и редактор уровней
- [x] Добавить панель целей в интерфейс игрока.
- [x] Поддержать до 4 целей на уровень.
- [x] Типы целей:
  - фишки выбранного цвета,
  - цель по всем цветам,
  - блокеры/препятствия.
- [x] Отображение прогресса в формате 'current / target'.
- [x] Доработать редактор уровня: ходы, цели, блокеры, автоподсчет выполнения.

**Критерий готовности:** дизайнер уровня может собрать и протестировать уровень целиком без ручных правок в коде.

## Этап 3. Бустеры и post-lose сценарии
- [x] Реализовать бустеры: ракета (вертикаль), лазер (горизонталь), area-burst (4x4 или комбинированный).
- [x] Добавить UX применения бустеров (кнопка/инвентарь/подсказка).
- [ ] Добавить lose-модалку с предложением докупить ходы/время через rewarded ad.
- [x] Синхронизировать логику бустеров с целями и препятствиями.

**Критерий готовности:** бустеры влияют на матч в рамках единых правил resolve, без рассинхрона HUD и счета.

## Этап 4. Визуал и оптимизация
- [x] Перейти на целевую палитру из 5 базовых цветов.
- [x] Нормализовать размер фишек внутри клетки (80-90%).
- [x] Добавить фоновые темы уровней (смена пользователем).
- [x] Расширить VFX-эффекты спец-фишек с учетом режима качества.
- [x] Выполнить профилирование и оптимизацию FPS на больших полях.

**Критерий готовности:** визуальные улучшения не ухудшают стабильность рендера и читаемость поля.

## Этап 5. Meta-слой и удержание

- [x] Добавить основного персонажа и нарративные вставки.

**Критерий готовности:** у игрока появляется понятная долгосрочная мотивация, не только "сыграть партию".

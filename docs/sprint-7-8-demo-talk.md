## Вступление · 2 мин.

Привет! Мы — команда 42, делаем игру "3 в ряд" Cosmic Match. Нас 5: Аня, Сергей, Артур, Антон и я, Кирилл, teamlead. Расскажу, что сделали в прошлых спринтах: **Express**, **SSR**, **Ya OAuth**, **лидерборд**, **форум на Postgres**, **темизация** и **авторизация на своём API**.

Стек игры: React + Redux на клиенте, **Express** отдаёт HTML и проксирует запросы, **Postgres в Docker** — наши данные, **API Практикум** — сессия и лидерборд. В спринтах 5–6 сделали UI и игровой движок; сегодня покажем, как это работает клиент-сервер. Начнем с фундамента — **7.1–7.2**.

## SSR и маршруты · (задачи  7.1 и 7.2)

**Как работает:** пользователь открывает URL → **Express** ('server/index.ts') отдаёт не пустой 'index.html', а гонит **React на сервере** ('entry-server.tsx'): Router собирает дерево страницы, Redux делает 'fetchData' для нужных slice’ов, в HTML попадает разметка **и** JSON в 'window.APP_INITIAL_STATE'. Браузер подхватывает ('main.tsx') — это **гидратация**: тот же UI без "мигания" и уже с начальными данными (состоянием).

**Как посмотреть:** View Source на главной — ищем 'APP_INITIAL_STATE'. '/health' — жив ли наш Node.

**Защита маршрутов:** 'withAuthGuard' на сервере смотрит store: если нет пользователя — в HTML  редирект на логин. Можно обновить '/forum' без сессии — увидите уход на login.

*Вывод:* SSR - это хорошо для SEO + честный первый кадр + данные из Redux.

## OAuth Яндекс · (задача 7.3)

**Как работает:** кнопка «Войти через Яндекс» ведёт на OAuth с 'redirect_uri' на **наш origin :9000** (whitelist Практикума). После согласия — callback, код меняем на сессию через API Практикума. Браузер ходит на **'/api/v2'** same-origin — **apiProxy** пересылает cookie на 'ya-praktikum.tech', чтобы сессия жила на домене приложения.

**Как посмотреть:** '/login' — кнопка и поля. Если env настроен — короткий live-вход; если нет — «вот кнопка, вот 'oauthApi.ts' и маршрут callback, поток тот же».

*Вывод:* OAuth без своего IdP — доверяем Практикуму, прокси держит cookie на одном origin.

## Лидерборд · (задача 7.4)

**Как работает:** 'leaderboardSlice' после логина дергает **'POST /api/v2/leaderboard/cosmicMatch42_bestScore'** — это уже **внешний** API, не наш Postgres. Ответ маппим в таблицу на 'LeaderboardPage': место, ник, очки.

**Как посмотреть:** '/leaderboard' — таблица с реальными данными. DevTools → Network — наш POST через прокси, статус 200 с данными.

*Одной фразой:* лидерборд = контракт Практикума + Redux, храним только отображение.

## Postgres в Docker · (задача 8.1)

**Как работает:** 'docker compose' поднимает **postgres:16** на порту **5433** (чтобы не драться с локальным brew на 5432). **Sequelize-миграции** создают таблицы форума и 'ui_theme'. Сервер без БД — 'ECONNREFUSED', поэтому перед демо всегда 'docker compose up -d postgres' и 'yarn db:migrate'.

**Как посмотреть:** терминал — 'docker compose ps', одна строка «миграции прошли».

*Вывод:* в Postgres живут темы и форум; Практикум отвечает за auth и лидерборд.

## Темизация UI · (задачи 8.3, 8.7)

**Как работает (на клиенте):** 'LandingThemeContext' вешает класс на 'body' — 'light-flat', 'light-3d', 'dark-neon'; выбор в **localStorage** и в шапке.

**Как работает (на сервере):** 'PUT /api/ui/theme' — гость получает cookie 'anonymous_session_id', залогиненный — запись в БД. После входа 'useThemeServerSync' подтягивает тему с сервера, чтобы F5 на другом устройстве не сбрасывал стиль.

**Как посмотреть:** переключить тему на '/' или '/game' → Network → 'PUT /api/ui/theme', потом 'GET' при перезагрузке.

*Кратко* тема видна сразу на клиенте, переживает сессию через наш API.

## Прокси и auth · (задачи 8.4, 8.8)

**Как работает:** один origin **:9000** — и UI, и API. 'apiProxy.ts' режет трафик: **'/api/v2' → Практикум**, **'/api/forum' и '/api/ui' → наш Node :3000**. Cookie переписываются на наш домен — иначе браузер их не отправит.

На Node **'requirePraktikumAuth'**: 'resolvePraktikumUser' дергает 'GET /auth/user' у Практикума по cookie; нет сессии — **403 Forbidden**, не «пустой JSON».

**Как посмотреть:** инкогнито → запрос '/api/forum/topics' → 403 с 'reason: Forbidden'. С логином — 200.

*Кратко:* прокси = один домен для фронта; middleware = форум только для своих.

## Форум — главный блок · (задачи 8.2, 8.5, 8.6, 8.9)

**Как работает (бэкенд):** 'forumRouter' — REST: топики, дерево комментариев, CRUD, модераторы по whitelist id. Реакции — отдельная таблица, **UNIQUE** на (комментарий, пользователь, эмодзи), whitelist emoji в 'forumEmojiGuard'.

**Как работает (клиент):** 'forumApi' + thunks в 'forumSlice'. Список тем показывает два счётчика: **Комментарии** (корневые) и **Ответы** (вложенные) — чтобы с первого экрана было видно активность. На странице темы — 'ForumCommentReactions': picker 🙂, чипы, toggle без перезагрузки страницы.

**Как посмотреть форум:**

1. '/forum' — список после логина.  
2. «+ Новая тема» — POST, тема в списке.  
3. Открыть тему — текст + лента.  
4. Комментарий → счётчик **Комментарии** +1.  
5. «Ответить» → вложенный блок, **Ответы** +1.  
6. 🙂 → эмодзи-чип; повтор — снять реакцию.  
7. Выйти / инкогнито — редирект или 403 (связка с 8.4).

*Кратко:* форум живет в нашем Postgres и пользует наш API; UX — дерево, счётчики, реакции в один клик.

## Памятка по компонентам:

| Компонент | Что делает |
| --- | --- |
| 'entry-server.tsx' | Собирает HTML + 'APP_INITIAL_STATE' под конкретный URL до ответа браузеру. |
| 'withAuthGuard' | На SSR не пускает в защищённый route без user в store. |
| 'apiProxy.ts' | Same-origin: '/api/v2' наружу, '/api/forum' и '/api/ui' на наш Node. |
| 'requirePraktikumAuth' | Проверяет cookie через Практикум; без сессии — 403. |
| 'forumRouter' | CRUD топиков/комментариев + реакции в Postgres. |
| 'forumSlice' | Redux: список, тема, optimistic toggle реакций, редирект на login при 403. |
| 'LandingThemeContext' | Класс на 'body' + sync с 'PUT/GET /api/ui/theme'. |
| 'performanceMetrics' | Mark/measure + long tasks в консоль на время сессии игры. |
